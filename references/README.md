## 查阅索引指南

- **查格局成败与月令取用**：直接翻阅 [`ziping_zhenquan/`](./ziping_zhenquan/) 各格局章节。
- **查十天干生于某月气候调候用神**：直接翻阅 [`qiongtong_baojian/`](./qiongtong_baojian/) 对应天干文件（如 `001穷通宝鉴：论甲木.md`）。
- **查天干地支气象、刚柔、寒暖、顺逆**：查阅 [`ditiansui_original/`](./ditiansui_original/) 或 [`ditiansui_chanwei/`](./ditiansui_chanwei/)。
- **查经典赋文（继善篇、碧渊赋等）**：查阅 [`yuanhai_ziping/`](./yuanhai_ziping/) 下的赋论篇章。
- **查病药说、动静说、雕琢废弃说**：查阅 [`shenfeng_tongkao/`](./shenfeng_tongkao/) 卷一至卷三。
